Konfigurasi Google Spreadsheet

Mode Data
Pilih antara data live Google Sheet atau data simulasi demo

Bisa berupa URL lengkap dokumen Google Sheet atau hanya ID Spreadsheet-nya saja.

Sesuai petunjuk sistem, default tab yang digunakan adalah "DATA".

Referensi Mapping Kolom Otomatis:
  • Kolom C: ARTICLE (Nomor Article / Kode Barang)
  • Kolom D: NAMA BARANG (Deskripsi Nama Barang)
  • Kolom E: QTY (Jumlah Kuantitas Barang)
  • Kolom P: LINE (Data nomor Line staging per pallet/barang)
  • Kolom O: LINE (Penyesuaian nomor line / alokasi staging line pintu)
  • Kolom Q: PINTU (contoh: "P08", "P11" diubah jadi 8, 11)
  • Kolom R: TYPE ARMADA (contoh: "CDD", "Wingbox")
  • Kolom S: PIC (Nama Petugas / Checker yang bertugas)
  • Kolom T: CBM ARMADA (Kapasitas CBM, contoh: 15, 11, 37)
  • Kolom F: ROUTE (berfungsi sebagai No. LC)
  • Kolom K: STATUS 2 (filter regex nomor ST/BR, contoh: /ST0\d+/ atau /BR0\d+/)
  • Kolom G: CUBE (volume CBM pallet - dipivot dan dijumlahkan per nomor ST)
  • Kolom L & M: LOADED (status muat / jam muat)
PENTING: Pastikan spreadsheet Anda memiliki hak akses: "Siapa saja yang memiliki link dapat melihat" (Anyone with the link can view), agar Google Visualization API dapat membaca datanya secara client-side.
